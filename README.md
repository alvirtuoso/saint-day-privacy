# Saint Day — Privacy Policy

The published privacy policy for the Saint Day app (iOS and Android), served with GitHub Pages:

**https://alvirtuoso.github.io/saint-day-privacy/**

## Source

The page is a copy of `privacy-policy.html` from the private `alvirtuoso/saintDay` repository, which is the source of truth. Edit the policy there, then copy it here as `index.html` and push:

```sh
cp privacy-policy.html index.html   # from the root of alvirtuoso/saintDay
git commit -am "docs: sync privacy policy"
git push
```

Any change to this page goes live within about a minute of the push.

## Content rules

- The policy must stay consistent with what the apps actually do: no accounts, no networking, no analytics or advertising SDKs, local-only reminder settings, and links handed off to the device browser.
- Contact address: info@lahat.org

## Files

- `index.html` — the published policy (no external assets, no scripts).
